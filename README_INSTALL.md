# Installing Granite Studios

Granite Studios isn't sold through the Windows or Mac app stores, so your
computer doesn't recognize it yet and will show a security warning the
first time you open it. This is completely normal for independent apps —
just follow the steps below once, and it'll open normally from then on.

---

## Windows

1. Download the `.zip` file and extract it (right-click → **Extract All**).
2. Open the extracted folder and double-click **GraniteStudios.exe**.
3. You'll likely see a blue **"Windows protected your PC"** screen. This is
   Windows SmartScreen — it shows up for any app that isn't from a big,
   registered publisher, even safe ones.
4. Click **More info**.
5. A **Run anyway** button will appear at the bottom — click it.
6. Granite Studios will open. You won't see this warning again on this
   computer.

A **Granite Studios** shortcut is automatically added to your Desktop and
Start Menu the first time it runs, so you can launch it normally after that.

---

## Mac

1. Download the `.dmg` file and double-click it to open it.
2. Drag the **Granite Studios** icon into the **Applications** folder shown
   in the window.
3. Open **Applications** (or Launchpad) and find **Granite Studios**.
4. **Right-click** (or Control-click) the app icon and choose **Open** from
   the menu — do **not** just double-click it the first time.
5. A dialog will say Apple can't verify the app is free of malware. Click
   **Open** to confirm.
6. Granite Studios will launch. From now on, you can open it normally by
   double-clicking.

*(This extra step is macOS's Gatekeeper feature, which flags any app that
isn't distributed through the Mac App Store — it's a standard step for
independent apps, not a sign anything is wrong.)*

---

## Still stuck?

If the app won't open at all, make sure you extracted the full `.zip`
(Windows) or dragged the app out of the `.dmg` into Applications (Mac)
rather than trying to run it from inside the downloaded archive.
